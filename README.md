# Leave Management System

 **[Live Demo](https://drive.google.com/file/d/1LE5tvACK5trIeOnqJqD3dVahcWQk8jt_/view?usp=drive_link)**

A full-stack web application designed to **streamline employee leave management** within an organization.  
Employees can apply for leaves, and admins can efficiently review, approve, or reject requests through an intuitive dashboard.  
This project eliminates manual tracking and ensures transparency in the leave process.

---

## Overview

The system enables:
- Employees to request leaves and check their history.
- Admins to manage, approve, or reject leaves.
- A responsive, role-based dashboard experience built with modern web technologies.

---

## Features

- **User Authentication** – Secure JWT-based login & signup.  
- **Role-Based Access** – Separate dashboards for Admins and Employees.  
- **Leave Operations** – Apply, Approve, Reject, and View leave requests.  
- **Leave History** – Track all approved, pending, or rejected leaves.  
- **Admin Dashboard** – Manage all employee leave requests in one place.  
- **Responsive Design** – Works seamlessly on both desktop and mobile.  
- **Real-Time Updates** – Instantly reflects status changes (email notifications not implemented yet).

## Tech Stack

### **Frontend**
- React.js  
- Tailwind CSS

### **Backend**
- Node.js  
- Express.js  

### **Database**
- MongoDB (Mongoose ODM)
